GEORGE: A new working paper by Liu Zhang and Mark Esposito, from this month, marked preliminary. The question: once an agent is deployed, are its evaluation scores comparable over time, and how long does an evaluation stay valid? And they study it on a real production agent.
MIA: Which agent?
GEORGE: It's called Zara, a voice-and-video agent that runs live job interviews for a company called micro1, at roughly thirty-two to ninety-one thousand interviews a week. MIA: And the problem is that everything moves at once.
GEORGE: Exactly. The agent changes, the users change, and the raters change, so a raw score trend mixes all three. MIA: Start with the raters, because that's the bit that hit home for me.

MIA: That's enormous.
GEORGE: It is. And here's the striking statistic. Batch fixed effects, meaning which fortnight a recording came from, explain one point four percent of score variance. MIA: So the raw trend looks flat.

MIA: So the team improved the agent by half a standard deviation and their dashboard said nothing happened.
GEORGE: Precisely. And economists will recognise the fix. It's the same identification argument as the AKM worker-firm models or judge fixed effects. You can only separate rater severity from agent quality if raters overlap within batches, so the graph linking raters and batches is connected. If B had scored only the later batches alone, you couldn't tell a harsh rater from a worse agent.
MIA: Is severity just one number per rater?
GEORGE: No, and this is the subtle part. It's a vector. B was one point four standard deviations harsher on latency but only zero point one three on conversation structure. GEORGE: Once you have q, uncertainty about where your agent is today grows linearly with time since the last evaluation.
